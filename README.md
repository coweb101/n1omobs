This repository stores scripts used to aggregate and analyze the EEG data, and plot the results. Plots showing model results only (Fig. 5 and Fig. S4) can be recreated using the data files in the folder aggregated_data. For recreating plots showing additionally the data underlying analyses (grand averages) or for reproducing the analyses yourself, please get the data via https://doi.org/10.17605/OSF.IO/3P96E
